How it works

1

Agent calls the endpoint

An AI agent requests a URL with query params — no signup, no API key, no rate limits.

2

Pays per request in USDC

The endpoint returns HTTP 402; the agent's x402 wallet pays the exact per-record price on Base.

3

Gets clean JSON back

On payment, live results return instantly as structured JSON. Pay only for what you use.

npx awal x402 pay "https://techforce-agents.onrender.com/api/business-leads" \
